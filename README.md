# Христианский арт-курорт на Пхукете

Инвестиционный меморандум с интерактивной финансовой моделью. Предварительная версия для обсуждения — не инвестиционное предложение и не замена due diligence.

**📊 [Открыть меморандум](https://a1exxx.github.io/phuket-christian-resort/)**

---

## Что это

Проект комплекса на острове Пхукет: монументальный арт-парк со скульптурой Христа и ангелами, многоэтажное премиальное кафе, церковь, бутик-отель и молитвенное служение. Позиционирование — арт-объект мирового уровня по модели Белого храма в Чианг Рае, а не паломнический центр.

Документ содержит 12 разделов, 9 архитектурных рендеров в трёх стилевых направлениях и **живой калькулятор на 23 бегунка**: инвестиции, выручка, EBITDA, IRR, окупаемость и точка безубыточности пересчитываются мгновенно.

## Три вывода, ради которых стоит открыть

1. **Отель разбавляет доходность.** Рост с 30 до 70 номеров меняет доходность на −0.1 процентного пункта: отель добавляет столько же капитала, сколько приносит выручки.
2. **Поток посетителей решает всё.** Рост с 600 до 2 700 человек в день даёт +11 процентных пунктов доходности. Все прочие рычаги — от 1 до 4.
3. **Фаза 1 без отеля ($5.9M) выигрывает у полного комплекса ($15.1M)** на любом уровне потока: при 1 000 гостей в день это 13.6% против 8.6%.

## Ограничения, найденные в ресёрче

- **Участок на вершине горы юридически недоступен.** По уведомлению MNRE (Royal Gazette 13.12.2024) выше 140 м застройка запрещена, а полоса 80–140 м открыта только для земли, приобретённой до 2017 года. Реалистично: ниже 80 м, уклон до 20%.
- **Христианские паломнические туроператоры в Таиланд не возят** — их маршруты идут только по местам библейской истории. Модель спроса построена на перехвате туристов, уже находящихся на острове.

Полный список источников — в футере документа.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Собранный меморандум, самодостаточный (картинки внутри как base64) |
| `master.template.html` | Шаблон вёрстки с плейсхолдерами `{{IMG_*}}` и `{{MODEL_JS}}` |
| `model.js` | Движок финансовой модели, без зависимостей |
| `build-master.mjs` | Сборка: сжимает картинки, встраивает всё в один файл |
| `test-model.mjs` | Тесты модели: пресеты, крайние значения, сходимость IRR |
| `sensitivity.mjs` | Анализ чувствительности — какой рычаг решает |
| `phasing.mjs` | Проверка гипотезы фазирования |
| `images/` | Рендеры: 3 стиля × 3 ракурса |
| `business-plan.html` | Предыдущая версия — кафе со статуей, до расширения проекта |

## Пересборка

Требуются Node.js и ffmpeg.

```bash
node test-model.mjs && node build-master.mjs
```

Правки модели идут в `model.js`, правки вёрстки — в `master.template.html`. Напрямую `index.html` не редактируется: он перезаписывается сборкой.

## Полезные команды

Анализ чувствительности — какой параметр сильнее всего двигает доходность:

```bash
node sensitivity.mjs
```

Сравнение фазы 1 с полным комплексом при разном потоке:

```bash
node phasing.mjs
```
